## ✨ Sobre o Projeto

O **Number Generator Pro** é uma aplicação web projetada para gerar números aleatórios com uma experiência elegante e interativa.

Inspirado em interfaces modernas, o projeto utiliza:

* 🌈 Gradientes animados
* 🧊 Glassmorphism
* ⚡ Microinterações
* 🎯 UI focada em UX

---

## 🚀 Funcionalidades

* 🔢 Definir intervalo (**mínimo e máximo**)
* ⚡ Geração instantânea de números
* 🎨 Interface moderna e animada
* 📱 Design responsivo (mobile + desktop)
* ✨ Animação dinâmica no resultado
